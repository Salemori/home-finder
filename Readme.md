# Home Finder

**Home Finder** is a property listing and discovery platform that allows users to search, filter, and save real estate properties for rent or sale. It is designed to simplify the process of finding suitable homes by providing advanced filtering, detailed property data, and user-friendly interactions.

## Features

- Property listing and management
- Search and filtering by:
  - Location (city, state)
  - Price range
  - Property type
  - Number of bedrooms, bathrooms, and toilets
  - Purchase type (sale or lease)
- Save and unsave favorite properties
- User authentication and authorization
- Admin and agent roles for managing listings
- MongoDB/Mongoose integration for efficient data querying

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT-based auth
- **Deployment**: Render
